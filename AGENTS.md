# Esep: короткий вход в проект

Общаться с пользователем по-русски. Текущий приоритет — веб-пилот для бухгалтеров; ТОО/ИП и баги Connect позже.

## Контекст без повторного полного аудита

1. Сначала прочитать `docs/PROJECT_STATE.md`.
2. Для конкретной задачи открыть только указанные там исходники и нужные строки `docs/PROJECT_AUDIT_LOG.md`.
3. `CLAUDE.md` и `HANDOFF.md` — исторические материалы. Их заявления о проде, ставках, ключах и результатах тестов не считать текущими фактами без проверки. Не выводить секреты из них.
4. Исключать из широких поисков `node_modules`, `docs/forms`, собранные JS, выгрузки лидов и контекстные XML. Использовать `rg` с узкой областью и ограниченным выводом.
5. `tools/context` содержит локальный Repomix. Использовать только точечный пакет нужного модуля, не загружать весь проект в контекст автоматически.
